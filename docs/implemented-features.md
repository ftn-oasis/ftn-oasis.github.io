## グローバルヘッダー (`src/components/layout/Header.tsx`)

ページ上部に常に表示される, GitHub のグローバルヘッダーを参考にした1行レイアウトです.

- **左**: ハンバーガーメニュー → 左からスライドインするナビゲーションドロワー
  (`NavDrawer`) を開閉, ロゴ (ホームへのリンク), 現在地のパンくず表示.
- **中央**: 検索ボタン. 幅に余裕があれば「検索…」というテキスト付きの横長ボタン, 狭い画面では
  虫眼鏡アイコンだけの正方形ボタンに自動で切り替わります. 押しても検索は未実装です.
- **右**: 「作成」ドロップダウン (会計申請/改善点の指摘/文書作成/文書アップロード/組織作成へのショートカット),
  主要ページへのアイコンリンク (改善点の指摘/修正の提案/全ての文書/全ての会計申請/予定されている会議),
  通知アイコン, ユーザーメニュー (アバター).
  画面が狭くなると「作成」「通知」「アバター」以外のアイコンが自動的に隠れ, 右詰めになります.

### パンくず

ロゴの右に現在パスを表示します. 通常は2階層まで (`issues / new` のように), 最下層 (現在表示中の
ページ) だけボールド表示です. `settings`/`documents`/`organizations`/`meetings`/`books`
のような固定ページは階層に関わらず1階層目だけを, 日本語の表示名 (設定/規則・資料/組織/会議/帳簿)
で表示します. ユーザーのプロフィールページ (`/<ユーザーID>`) も同様に, パスではなくユーザー名を
表示します.

### ナビゲーションドロワー (`NavDrawer`)

ハンバーガーメニューから開く, 画面左からスライドインするドロワーです. ホーム, 各種申請/報告/提案
へのリンク, 会議・文書, 区切り線を挟んで規則等・組織へのリンク (実ドメイン未確定のためプレース
ホルダーURL), 最下部に「問題を報告」ボタン (未実装) があります.

### ドロップダウン/ポップオーバー (「作成」ボタン, ユーザーメニュー)

ボタン直下に浮くパネルとして開きます. パネル外クリックか Escape キーで閉じます.

- **「作成」**: 会計申請の作成 (モーダル, 未実装), 改善点の指摘/文書作成/文書アップロード/組織作成
  へのリンク.
- **ユーザーメニュー**: アバター + ユーザー名 + メールアドレス (プロフィールページへのリンク),
  設定, 外観 (テーマ設定ページ, 未実装), ログアウト (未実装).

## テーマ (ライト/ダーク)

Catppuccin (Latte=ライト, Mocha=ダーク) をベースにしたカラーテーマです.

- 初回表示時は OS の `prefers-color-scheme` 設定を自動検出して初期テーマを決めます.
- アプリを開いたまま OS 側のテーマ設定を変更すると, サイトのテーマも自動で追従します.
- 手動でテーマを切り替えると, そのセッション中は OS 側の変更より手動選択を優先します.
- ページ再読み込みで手動選択は失われます (localStorage 等への永続化は未実装).
- 手動切り替え用の `ToggleThemeButton` コンポーネント自体は動作しますが, まだ実際の画面
  (ユーザーメニューの「外観」など) には接続されていません.

## UI コンポーネントライブラリ (`src/components/ui/`)

今後ページを作る際に再利用できる, 汎用的な部品群です.

- **`IconButton` / `IconLink`** — アイコン (Tabler Icons) を表示する正方形のボタン/リンク.
  ホバー時にラベルをツールチップ表示します. ドロップダウン用の矢印表示, 横に伸びてテキストも
  表示する「検索ボタン」風の見た目, ツールチップの非表示化など複数のバリエーションに対応.
- **`MenuLink`** — アイコン+可視ラベルを横並びで表示する, ドロワーやドロップダウンの中の行.
  内部リンク/外部リンクどちらも扱えます.
- **`Avater`** (アバター画像), **`Divider`** (区切り線), **`Emblem`** (ロゴマーク SVG) など.
- 開閉+外側クリック/Escape で閉じるポップオーバーの共通ロジック (`useDismissablePopover`),
  ツールチップが画面端で見切れないように自動調整する `useTooltipAlign` など, 挙動を共通化する
  フック群.
